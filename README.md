# MALANG Rehab

압력센서 기반 스마트 말랑이와 Unity 게임을 연결해 손의 쥐기, 힘 유지, 힘 조절, 놓기 동작을 연습하는 산학프로젝트입니다. 현재 시제품 개발 단계입니다.

## 개발 목표

- 말랑이를 쥘 때의 압력 변화를 센서로 수집
- 사용자별 입력 범위를 0~100%로 보정
- Unity 게임에서 실시간 힘 피드백 제공
- 게임 수행 결과와 훈련 기록 저장
- 관리자 웹에서 훈련 기록 조회

## 시스템 구성

압력센서 → ESP32 → Unity 앱 → 훈련 기록 저장 → 관리자 웹

## 개발 순서

1. 센서값 수집 및 쥐기·유지·놓기 신호 확인
2. Unity 가상 입력과 힘 게이지 구현
3. 실제 센서 입력 및 개인별 보정 연결
4. 단계별 게임 구현
5. 기록 저장 및 관리자 웹 연동

## 프로젝트 상태

개발 초기 단계입니다. 센서 배치, 게임 판정 기준, 세부 기술 구성은 시제품 시험 결과에 따라 확정합니다.
